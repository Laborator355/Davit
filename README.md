## 5. Եզրակացություն / Բացատրություն

Hardware Fingerprint-ը համակարգչի ֆիզիկական բաղադրիչների (պրոցեսորի մոդել, ցանցային քարտի MAC հասցե, սկավառակի ծավալ) հիման վրա ստեղծված ունիկալ իդենտիֆիկատոր է: 
Կիբեռանվտանգության ոլորտում այս մեթոդը լայնորեն կիրառվում է ծրագրերի արտոնագրման (DRM ռազմավարություն), սարքերի ճանաչման և պաշտպանական այլ համակարգերում (օրինակ՝ anti-cheat): 
Որպեսզի համակարգչի իրական պարամետրերը բացահայտ չպահպանվեն, կիրառվում է հեշավորում (մասնավորապես SHA256 ալգորիթմը): Այնուամենայնիվ, այս մոտեցումն ունի խոցելիություն. օպերացիոն համակարգի մակարդակով որոշ տվյալներ, ինչպիսին է MAC հասցեն, հնարավոր է հեշտությամբ կեղծել (MAC spoofing)՝ այդպիսով շրջանցելով աուտենտիֆիկացիան:
